# IMDb Sentiment Analysis using NLP

## 📌 Project Overview
This project performs end-to-end sentiment analysis on IMDb movie reviews using Natural Language Processing (NLP) and Machine Learning techniques. Reviews are classified as **Positive** or **Negative** based on textual content.

## 📂 Dataset
IMDb movie reviews dataset containing review text and ratings.

## ⚙️ Techniques Used
- Text Cleaning & Preprocessing (NLTK)
- TF-IDF Vectorization (Unigrams & Bigrams)
- Machine Learning Models:
  - Logistic Regression
  - Naive Bayes
  - Support Vector Machine (SVM)
  - Random Forest
- Hyperparameter Tuning (GridSearchCV)

## 📊 Model Performance
- **Best Model:** Support Vector Machine (SVM)
- **Accuracy:** ~93%
- Logistic Regression, Naive Bayes, and Random Forest achieved ~90% accuracy.

## 📈 Visualizations
- WordClouds for Positive & Negative Reviews
- Confusion Matrix
- Model Comparison Bar Chart

## 🧪 Custom Predictions
The trained model supports prediction on new movie reviews.

- Python
- Pandas, NumPy
- NLTK
