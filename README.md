# IMDB Movie Review Sentiment Analysis using Machine Learning

## Project Overview

This project focuses on performing sentiment analysis on movie reviews from the IMDB dataset.

The goal is to classify each review as **positive** or **negative** using Natural Language Processing (NLP) and Machine Learning techniques.

Sentiment analysis is widely used to understand public opinion, customer feedback, and product reviews.

---

## Objectives

* Preprocess textual movie review data
* Convert text into numerical features
* Train machine learning models for sentiment classification
* Evaluate model performance

---

## Dataset

The dataset consists of movie reviews collected from IMDB.

Each review is labeled as:

* **Positive** – favorable opinion about the movie
* **Negative** – unfavorable opinion about the movie

This is a **binary text classification problem**.

---

## Tools and Technologies

The project was implemented using:

* Python
* Pandas
* NumPy
* Scikit-learn
* Natural Language Processing techniques

---

## Methodology

### Text Preprocessing

* Lowercasing text
* Removing punctuation
* Removing stopwords
* Tokenization

### Feature Extraction

* TF-IDF vectorization of text data

### Model Training

The following machine learning algorithms were used:

* Logistic Regression
* Naive Bayes
* Support Vector Machine

### Model Evaluation

Model performance was evaluated using:

* Accuracy
* Confusion Matrix

---

## Results

The trained models successfully classified movie reviews based on sentiment.

The analysis demonstrates how textual data can be transformed into meaningful features for predictive modeling.
